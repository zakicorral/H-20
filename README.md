# H-20 — Investigation Game

An original mobile-first mystery game built around a fictional case that gradually becomes personal.

## Current build

- 5 investigation chapters
- persistent local save state
- evidence inventory
- recovered phone interface
- locked/unlocked phone apps
- searchable scene with irrelevant objects
- multi-step evidence-dependent puzzles
- family index deduction
- relationship/internship connection puzzle
- final date lock and FILE 020 reveal
- responsive mobile UI with large touch targets

## Story rule

The investigation should feel like a genuine mystery first. The birthday connection is deliberately withheld until the final file.
